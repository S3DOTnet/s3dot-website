# S3DOT 開発日報

## 本日の目的

- ナイトワーク店舗向け管理システムの共同開発構想を整理し、現場課題と段階的な導入方針を共有する

## 実施内容

### 店舗管理システム構想の打ち合わせ

- 紙、Excel、LINEへ分散している日報、売上、シフト、給与関連業務を一つの仕組みにまとめる方向性を検討
- 日報のOCR取込、PC・タブレットからの直接入力、LINEへの報告連携を候補として整理
- シフト希望の収集と調整、勤怠、給与の見える化、在庫、顧客・ボトル管理、ランキング、匿名フィードバックなどの機能案を洗い出し
- 最初から全機能を導入せず、試験店舗での現場観察と短期運用を通じて段階的に広げる方針を確認
- 店舗ごとの権限、個人情報、外部サービス連携、運用ルールを初期設計で明確にする必要性を共有

## 問題と解決

- 問題: 店舗業務が複数の紙・表計算・メッセージ手段へ分散し、二重入力や確認負荷が大きい
- 解決: 一気に置き換えず、優先業務を定めた試験導入と現場フィードバックで設計を固める方針とした
